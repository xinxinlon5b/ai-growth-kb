A3 · 《Evaluating AI agents in real enterprise workflows》企业 Agent 评估方法论

类型：一手权威 · 评估方法论
发布：Anthropic
链接：anthropic.com（评估专题）
中文卡版本：基于摘要整理 · 2026-09-10

一、定位

A1 讲 FDE 是什么，A2 讲 Agent 怎么造，A3 讲 Agent 怎么证明自己能用。

这是「怎么证明 AI 真的把客户的钱省下来了」的权威答案。
你的 SOP-01「按省钱数字报价」需要的就是这套方法。

二、四大核心论点

1. 别只看准确率——要看业务指标

Agent 评估不能只测"模型答对了多少题"，要测：

层级 指标举例
模型层 准确率 / 召回率 / 幻觉率
任务层 完成率 / 平均步数 / 失败重试率
业务层 客户满意度 / 节省时间 / 减少错误
经济层 帮客户省了多少钱 / 提升多少产能

对应你 SOP-01 第 3 步"按省钱数字报价"——
业务指标 + 经济指标才是真评估。

2. 故障注入测试（Failure Injection Testing）

这是和 C2「混沌工程」一脉相承的工程实践。

主动制造异常：
- 给 Agent 一个故意错误的数据，看会不会出错
- 关掉一个工具，看会不会死循环
- 把工具返回结果延迟，看会不会超时
- 模拟用户故意误导，看会不会被骗

目的：不是证明 Agent 多强，是证明 Agent 在异常下不死。

对应你的"知识库项目 7 成是脏活"——故障注入就是最脏的活。

3. 边界验证（Boundary Verification）

Agent 的能力有边界，必须明确标注：

  • 能做：查询 X 库 / 修改 Y 字段 / 调用 Z 工具
  • 不能做：删除生产数据 / 修改客户合同 / 转账超过 X 元
  • 不确定：判断 Y 类型 / 评估 Z 风险

验证方法：用边界 case 测试集，确保"不能做"绝对不做。

对应 SOP-07「报价签约」里的"交付标准"——
必须白纸黑字写清楚 Agent 能做什么、不能做什么。

4. 可验证标准（Verifiable Criteria）

不要用"用户体验更好""效率提升"这种模糊指标。
要换成可量化、可自动测的指标：

❌ 模糊 ✓ 可验证
体验更好 客服响应时长从 30s 降到 5s
效率提升 单据处理从 4 小时降到 30 分钟
更准确 字段抽取准确率从 78% 升到 96%
客户满意 NPS 从 32 升到 58

对应你 SOP-07「报价签约」里的"价值量化"——必须可验证、可对账。

三、关键术语

英文 中文 释义
Failure Injection 故障注入 主动制造异常验证护栏
Boundary Verification 边界验证 明确 Agent 能/不能做什么
Verifiable Criteria 可验证标准 可量化的评估指标
Business Metric 业务指标 真实业务结果的指标

十一、4 层评估指标的计算方法

第 1 层：模型层指标（自动测）

准确率 = 答对数 / 总数
召回率 = 召回正确答案数 / 全部正确答案数
F1 = 2 × 准确率 × 召回率 / (准确率 + 召回率)
幻觉率 = 编造内容数 / 总回答数

自动化：用测试集 + 脚本比对，无需人工。

第 2 层：任务层指标（半自动测）

完成率 = 完整跑通的任务数 / 总任务数
平均步数 = 总步数 / 任务数
失败重试率 = 重试次数 / 总任务数
用户接管率 = 人工介入次数 / 总任务数

半自动：跑真实任务流 + 日志分析。

第 3 层：业务层指标（业务方定义）

客户满意度 = 5 分制平均分
节省时间 = 之前耗时 - 现在耗时
错误率下降 = (之前错误率 - 现在错误率) / 之前错误率

定义权在业务方——FDE 不能拍脑袋。

第 4 层：经济层指标（FDE 自证）

年节省 = Σ(业务流节省的年人时) × 时薪
客单价合理性 = 客户预算 / 年节省（建议 10-20%）
ROI = (年节省 - 项目费) / 项目费 × 100%

自证逻辑：能算清楚 ROI = 报价合理 = 续约有据。

十二、3 个客户说服话术

话术 1：建立评估基线

"在调优之前，我们先建一个 50-100 条的黄金集——
全部来自您真实业务素材，每条带标准答案。
用这个基线测出来 78% 准确率，调完模型升到 96%——
这就是我们的验收标准。"

话术 2：用业务指标不用模型指标

"模型准确率 95% 不等于业务有用——
业务指标是'客服响应时长从 30s 降到 5s'，
这是您能感知、您老板能看懂的指标。"

话术 3：把评估当续约条件

"上线后每月出一份评估报告——
准确率、响应时长、节省金额三项数字。
数据下降就触发模型调优，数据达标就触发续约谈判。"
