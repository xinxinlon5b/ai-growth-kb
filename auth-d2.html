D2 · AWS Well-Architected Framework —— 完整中文全文翻译

原文标题：AWS Well-Architected Framework
发布：2024 年 11 月 6 日（文档修订）
来源：https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html
翻译说明：以下为 AWS 官方文档的完整中文翻译，保留引言、配套服务、审查本质等核心内容。仅跳过原文中的纯 UI 元素（如 "Documentation / Security / Pricing / Sign in" 等页面导航）。

引言

"The AWS Well-Architected Framework helps you understand the pros and cons of decisions you make while building systems on AWS. By using the Framework you will learn architectural best practices for designing and operating reliable, secure, efficient, cost-effective, and sustainable systems in the cloud."

AWS Well-Architected Framework 帮助您了解在 AWS 上构建系统时所做决策的利弊。通过使用该框架，您将学习架构最佳实践，以在云中设计、运营可靠、安全、高效、经济和可持续的系统。

该框架提供了一种持续衡量您的架构是否符合最佳实践、识别需要改进领域的方式。审查架构的过程是关于架构决策的建设性对话，而不是审计机制。我们相信，拥有良好架构的系统极大地增加了业务成功的可能性。

"Using the Framework helps you learn architectural best practices for designing and operating secure, reliable, efficient, cost-effective, and sustainable workloads in the AWS Cloud."

使用该框架可帮助您学习在 AWS 云中设计、运营安全、可靠、高效、经济和可持续的工作负载的架构最佳实践。

"It provides a way for you to consistently measure your architectures against best practices and identify areas for improvement. The process for reviewing an architecture is a constructive conversation about architectural decisions, and is not an audit mechanism. We believe that having well-architected systems greatly increases the likelihood of business success."

它为您提供了一种持续衡量您的架构是否符合最佳实践、识别需要改进领域的方式。审查架构的过程是关于架构决策的建设性对话，而不是审计机制。我们相信，拥有良好架构的系统极大地增加了业务成功的可能性。

"AWS Solutions Architects have years of experience architecting solutions across a wide variety of business verticals and use cases. We have helped design and review thousands of customers' architectures on AWS. From this experience, we have identified best practices and core strategies for architecting systems in the cloud."

AWS 解决方案架构师拥有跨各种业务垂直领域和用例架构解决方案的多年经验。我们已经帮助设计和审查了 AWS 上数千个客户的架构。根据这些经验，我们确定了在云中架构系统的最佳实践和核心策略。

"The AWS Well-Architected Framework documents a set of foundational questions that help you to understand if a specific architecture aligns well with cloud best practices. The framework provides a consistent approach to evaluating systems against the qualities you expect from modern cloud-based systems, and the remediation that would be required to achieve those qualities."

AWS Well-Architected Framework 记录了一组基础性问题，帮助您了解特定架构是否与云最佳实践良好对齐。该框架提供了一种一致的方法，针对您对现代云系统所期望的品質来评估系统，以及实现这些品質所需的补救措施。

"As AWS continues to evolve, and we continue to learn more from working with our customers, we will continue to refine the definition of well-architected."

随着 AWS 不断演进，我们继续从与客户合作中学到更多，我们将继续完善良好架构的定义。

"This framework is intended for those in technology roles, such as chief technology officers (CTOs), architects, developers, and operations team members."

该框架面向技术角色的人员，如首席技术官（CTO）、架构师、开发人员和运营团队成员。

"It describes AWS best practices and strategies to use when designing and operating a cloud workload, and provides links to further implementation details and architectural patterns."

它描述了在设计和运营云工作负载时使用的 AWS 最佳实践和策略，并提供指向进一步实施细节和架构模式的链接。

"For more information, see the AWS Well-Architected homepage."

有关更多信息，请参阅 AWS Well-Architected 主页。

"AWS also provides a service for reviewing your workloads at no charge. The AWS Well-Architected Tool (AWS WA Tool) is a service in the cloud that provides a consistent process for you to review and measure your architecture using the AWS Well-Architected Framework. The AWS WA Tool provides recommendations for making your workloads more reliable, secure, efficient, and cost-effective."

AWS 还提供免费的工作负载审查服务。AWS Well-Architected Tool（AWS WA Tool）是云中的一项服务，为您提供使用 AWS Well-Architected Framework 审查和衡量架构的一致流程。AWS WA Tool 提供使您的工作负载更可靠、安全、高效和经济的建议。

"To help you apply best practices, we have created AWS Well-Architected Labs, which provides you with a repository of code and documentation to give you hands-on experience implementing best practices."

为了帮助您应用最佳实践，我们创建了 AWS Well-Architected Labs，它为您提供代码和文档存储库，让您获得实施最佳实践的动手经验。

"We also have teamed up with select AWS Partner Network (APN) Partners, who are members of the AWS Well-Architected Partner program."

我们还与精选的 AWS Partner Network（APN）合作伙伴合作，他们是 AWS Well-Architected 合作伙伴计划的成员。

"These AWS Partners have deep AWS knowledge, and can help you review and improve your workloads."

这些 AWS 合作伙伴具有深厚的 AWS 知识，可以帮助您审查和改进您的工作负载。
