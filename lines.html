05 · 话术弹药（22 句可复用金句 · 实战版）

见客户 / 写文案 / 做分享时可以直接用的句子。每句都标了使用场景 + 实战话术模板 + 出处。

一、开场引入（5 句）

# 场景 话术 出处 实战模板
01 给老板讲价值 「AI 不会凭空给你更好的业务能力，只会指数放大你沉淀的业务资产」 DD讲AI "我们不是卖 AI 工具，是帮您把已有的数据 / 流程 / 客户关系放大 10 倍——前提是您得先有这些资产。"
02 给老板讲组织 「未来组织就做两件事：运营的自动化 + 战略决策的高质量化」 曾鸣 "您公司未来 3 年的组织转型方向只有这两件事——其他都是噪音。"
03 讲清落地难点 「数据只是第一步，难的是把人的经验说清楚」 董俊豪 "30 万买工具，3 个月后只有行政用——难的不是技术，是经验沉淀。"
04 讲清前提 「没有数字化就没有全面的 AI 智能化」 旭东AI "您还在 Word/Excel 传文件的话，先补数字化课，再谈 AI。"
05 泼冷水/立专业 「工具是 0，业务才是 1，没 1 全白搭」 旭东38 "您想要 AI，但 AI 解决的不是'工具问题'，是'业务问题'——先有业务再上 AI。"

二、需求澄清（4 句）

# 场景 话术 出处 实战模板
06 立认知壁垒 「会用工具越来越不稀奇，能把内容为什么有效拆明白，才是商业精神力」 光羽 "会用 Cursor 的人满街都是，能说清'为什么这个 prompt 有效'的人凤毛麟角——后者才是商业价值。"
07 立定位 「工具不能赚钱，稀缺能力才能赚钱」 徐兆猛 "学 AI 工具不赚钱，把 AI 用到具体业务的能力才赚钱——这叫 FDE。"
08 FDE 三问第 1 问 「哪个环节最浪费时间？」 旭东AI "您团队每天最浪费时间的环节是什么？找出来就是 AI 的机会。"
09 FDE 三问第 2 问 「哪个部门天天重复劳动？」 旭东AI "哪个部门的工作是每天 / 每周重复但又必须有人做的？这是 AI 接管的首选。"

三、报价 / 价值（4 句）

# 场景 话术 出处 实战模板
10 讲获客 「一个视频 = 24 小时营业的销售」 清华鑫哥 "我每周发 2-3 条实战视频，每个视频 24 小时帮我在抖音上'站岗'——客户看到就找来。"
11 AI 落地两前提筛查 「客户想上 AI，先别急着报价。先判断他业务里有没有『真实 + 重复 + 能留下数据』的工作，以及 AI 做完人能否较快判断对错」 王总/董俊豪/旭东 "我先问您 3 个问题：哪个环节每天重复发生？数据能导出吗？做完人能 5 分钟判断对错吗？3 个都'是'，我们才接。"
12 四阶段渐进落地法 「导入-典范-扩展-生化」 旭东AI "我们不会一上来铺全公司——先在您最痛的一个业务做试点，跑通再复制。"
13 先盘业务资产再谈 AI 「AI 不会凭空给你业务能力，只会放大你已有的数据、流程和客户关系」 DD讲AI "在谈 AI 之前，我帮您盘一下：哪些业务资产可以被放大？放大了能省多少钱？这是我们报价的基础。"

四、交付 / 风险（5 句）

# 场景 话术 出处 实战模板
14 五步轻量交付 SOP 「业务诊断 → Demo → 实施 → 优化 → 培训」 旭东AI "我们的 5 步流程：先去您现场看 3 天真实业务，再搭 MVP 给您看，然后实施 + 优化 + 培训您内部负责人。"
15 把技术翻译成省钱 「老板买的不是 AI，是『少雇一个人』」 清华鑫哥 "这套方案上线后，您这个岗位每年省 15 万工资 + 社保 + 管理成本 = 18 万。"
16 知识库项目七成是脏活 「AI 只占 3 成功夫，7 成是帮客户梳理十年乱文档」 清华鑫哥 "知识库项目不是装个 RAG 就完——7 成时间在帮您理清楚那些'只有老员工知道'的隐性知识。"
17 先补数字化再谈 AI 「数据是 AI 的燃料，没燃料跑不起来」 旭东14 "您先把这些表标准化、能导出——AI 才有东西可吃。"
18 按业务复杂度报价 「客户问『一个 Agent 多少钱』时别急着报」 制造业AI落地官 "一个售后 Agent 要接产品型号、技术手册、保修政策、历史记录——不是 5 万能搞定的。先看您业务复杂度再报价。"

五、组织 / 战略（4 句）

# 场景 话术 出处 实战模板
19 用组织升级包装服务 「把工业时代组织改造成 AI 时代组织」 小智/曾鸣 "我们卖的不是 Agent，是您公司未来 3 年的组织升级——运营自动化 + 决策高质量化。"
20 先做刚性自动化再上 AI 「核心执行别依赖 AI 推理，先把专家经验写成固定代码」 智慧农业 "浇水这个事 AI 推理不可靠——写成'湿度 < 30% + 在 8-18 点 + 水位 > 50% = 自动开阀'，AI 只做交互层。"
21 用数据拆解伪需求 「客户说『AI 赋能』时先别开工」 字节产品经理 "模糊需求三连问：解决率多少？转人工率多少？用户在哪个环节流失？能答上来再开工。"
22 定位增长型策略问题 「改造企业流程时别被『体感痛』带偏」 程前 "剪辑麻烦（优化类）vs 选题预判（策略类）——优先做后者。体感痛但对增长无用的事要忍住先不做。"

六、实战使用指南

场景 1：30 分钟客户拜访

  • 开场（5 分钟）：用 #01 / #02 / #05 一句立调性
  • 需求澄清（10 分钟）：用 #08 / #09 / #11 三问挖痛点
  • 方案介绍（10 分钟）：用 #12 / #14 / #16 讲交付
  • 报价收尾（5 分钟）：用 #15 + 5 步报价法 Excel

场景 2：朋友圈 / 公众号

  • 每周 1 条 #01 / #05 / #07 立专业感
  • 每周 1 条 #10 / #19 立 FDE 定位
  • 每月 1 条 #04 / #11 立认知壁垒

场景 3：抖音口播

  • 钩子（0-3s）：#01 / #05 / #07
  • 冲突（3-10s）：#03 / #11 / #15
  • 展示（10-40s）：#12 / #14 / #16
  • 结论（40-60s）：#19 / #20

场景 4：内部周报 / 客户汇报

  • 用 #15 / #16 / #20 量化"我们做了什么"
  • 用 #11 / #21 把模糊需求翻译成数字

七、自检清单

每次用之前问自己：
- [ ] 这句话对这个客户合适吗？（不同行业不同话术）
- [ ] 我能在 30 秒内解释完吗？（不能解释的话术不适合口语）
- [ ] 有真实数据 / 案例支撑吗？（空话不如数据）
- [ ] 对方听完会想追问吗？（好话术引发好奇）
