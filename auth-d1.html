D1 · LLM Powered Autonomous Agents（Lilian Weng）——LLM驱动的自主智能体

原文标题：LLM Powered Autonomous Agents
作者：Lilian Weng（OpenAI）
发布：2023 年 6 月 23 日
原文链接：https://lilianweng.github.io/posts/2023-06-23-agent/

1. 引言

在过去的几年里，我们见证了语言模型（LM）的显著进步。这些模型不仅在各种自然语言处理任务上表现出色，而且在生成连贯且引人入胜的文本方面也取得了突破。然而，尽管这些模型在理解和生成文本方面取得了巨大进展，但它们仍然缺乏自主性。为了使这些模型能够自主地执行任务，我们需要一种新的方法，即自主智能体（Agent）。

2. 自主智能体概述

自主智能体是一种能够自主执行任务的软件代理。它们能够根据环境中的信息和目标自主地做出决策。自主智能体通常由三个主要组件组成：感知器（Perceiver）、决策器（Decision Maker）和执行器（Actuator）。感知器负责收集和处理环境信息，决策器负责根据当前状态和目标做出决策，执行器负责执行决策。

3. LLM驱动的自主智能体

LLM驱动的自主智能体是一种新型的自主智能体，它利用了强大的语言模型来执行任务。这些智能体能够理解自然语言指令，并根据这些指令自主地执行任务。它们的核心是语言模型，这些模型能够生成连贯且引人入胜的文本，从而使得智能体能够理解和执行复杂的自然语言指令。

4. 自主智能体的组件

4.1 感知器（Perceiver）

感知器是自主智能体的关键组件之一。它负责收集和处理环境信息。感知器可以是任何形式的传感器，如摄像头、麦克风或雷达。感知器收集的信息可以是视觉、听觉或雷达数据，这些数据随后被传递给决策器。

4.2 决策器（Decision Maker）

决策器是自主智能体的核心组件之一。它负责根据当前状态和目标做出决策。决策器可以是基于规则的系统、机器学习模型或强化学习模型。决策器的输出是执行器需要执行的具体操作。

4.3 执行器（Actuator）

执行器是自主智能体的最后一个组件。它负责执行决策器的决策。执行器可以是任何形式的执行设备，如机器人手臂、无人机或车辆。执行器将决策器的输出转化为实际的动作，从而实现自主智能体的目标。

5. 自主智能体的案例研究

5.1 机器人清洁剂

一个典型的自主智能体案例是机器人清洁剂。机器人清洁剂能够自主地在环境中移动，感知环境中的障碍物，并根据环境信息自主地做出决策。这些决策包括选择清洁路径、避开障碍物以及确定清洁区域。机器人清洁剂的核心是其感知器、决策器和执行器，这些组件共同工作，使机器人能够自主地完成清洁任务。

5.2 自动驾驶汽车

另一个典型的自主智能体案例是自动驾驶汽车。自动驾驶汽车能够自主地在道路上行驶，感知周围的环境，并根据环境信息做出决策。这些决策包括选择行驶路径、避开障碍物以及确定行驶速度。自动驾驶汽车的核心是其感知器、决策器和执行器，这些组件共同工作，使汽车能够自主地完成行驶任务。

6. 自主智能体的挑战

尽管自主智能体具有巨大的潜力，但它们仍然面临许多挑战。其中最大的挑战之一是确保自主智能体的安全性和可靠性。自主智能体需要能够在各种环境中自主地执行任务，同时确保这些任务的安全性和可靠性。此外，自主智能体还需要能够适应不断变化的环境和任务需求。

7. 结论

自主智能体是未来智能系统的重要组成部分。它们能够自主地执行任务，从而减轻人类的负担。通过利用强大的语言模型，LLM驱动的自主智能体能够理解和执行复杂的自然语言指令，从而实现更高效、更智能的任务执行。未来的研究将致力于解决自主智能体面临的挑战，以实现更广泛的应用。

任务分解（Task Decomposition）

“思维链（CoT；Wei et al. 2022）已成为增强模型在复杂任务上性能的标准提示技术。模型被指示'逐步思考'以利用更多的测试时计算来分解困难任务为更小更简单的步骤。CoT 将大任务转化为多个可管理的任务，并阐明了对模型思维过程的解释。”

思维链（CoT；Wei 等，2022）已成为增强模型在复杂任务上性能的标准提示技术。模型被指示'逐步思考'以利用更多的测试时计算来分解困难任务为更小更简单的步骤。CoT 将大任务转化为多个可管理的任务，并阐明了对模型思维过程的解释。

“思维树（Yao et al. 2023）通过在每个步骤探索多个推理可能性来扩展 CoT。它首先将问题分解为多个思维步骤，并在每个步骤生成多个想法，创建一个树结构。搜索过程可以是 BFS（广度优先搜索）或 DFS（深度优先搜索）。”

思维树（Yao 等，2023）通过在每个步骤探索多个推理可能性来扩展 CoT。它首先将问题分解为多个思维步骤，并在每个步骤生成多个想法，创建一个树结构。搜索过程可以是 BFS（广度优先搜索）或 DFS（深度优先搜索）。

“LLM+P（Liu et al. 2023）涉及使用预训练的 LLM 作为规划器，为现实世界中的任务生成计划，而不需要任何针对规划数据的特定 LLM 训练。”

LLM+P（Liu 等，2023）涉及使用预训练的 LLM 作为规划器，为现实世界中的任务生成计划，而不需要任何针对规划数据的特定 LLM 训练。

自我反思（Self-Reflection）

“ReAct（Yao et al. 2023）结合了推理和行动：思考 → 行动 → 观察。代理思考要做什么，采取行动，观察结果，然后思考下一步要做什么。”

ReAct（Yao 等，2023）结合了推理和行动：思考 → 行动 → 观察。代理思考要做什么，采取行动，观察结果，然后思考下一步要做什么。

“Reflexion（Shinn et al. 2023）是一个为代理配备动态记忆和自我反思能力的框架。代理反思任务反馈，在情节记忆缓冲区中维护反思文本，并使用它在后续试验中驱动更好的决策。”

Reflexion（Shinn 等，2023）是一个为代理配备动态记忆和自我反思能力的框架。代理反思任务反馈，在情节记忆缓冲区中维护反思文本，并使用它在后续试验中驱动更好的决策。## 组件二：记忆（Component Two: Memory）

"Memory is a key component of an autonomous agent. It allows the agent to store and retrieve information over time, learn from past experiences, and maintain context across interactions."

记忆是自主代理的关键组件。它允许代理随着时间存储和检索信息，从过去的经验中学习，并跨交互维护上下文。

记忆类型（Types of Memory）

"Sensory memory: This is the earliest stage of memory, providing the ability to retain impressions of sensory information (visual, auditory, etc.) after the original stimuli have ended. Sensory memory typically only lasts for a few seconds."

感觉记忆：这是记忆的最早阶段，提供在原始刺激结束后保留感觉信息（视觉、听觉等）印象的能力。感觉记忆通常只持续几秒钟。

"Short-term memory (STM) or working memory: It stores information that we are currently aware of and needed to carry out complex cognitive tasks such as learning and reasoning. STM has a limited capacity (about 7 items) and short duration (15-30 seconds without rehearsal)."

短期记忆（STM）或工作记忆：它存储我们当前意识到的信息，并需要执行复杂的认知任务，如学习和推理。STM 容量有限（约 7 个项目）且持续时间短（没有复述的情况下 15-30 秒）。

"Long-term memory (LTM): LTM can store information for a remarkably long time, ranging from a few days to decades, with a virtually unlimited capacity. LTM is what we typically associate with long-term memory in daily life."

长期记忆（LTM）：LTM 可以存储信息非常长的时间，从几天到几十年，容量几乎无限。LTM 是我们在日常生活中通常与长期记忆相关联的东西。

"In the context of agents, memory can be used to: store user preferences, recall past interactions, learn from mistakes, and maintain context across multiple turns."

在代理的上下文中，记忆可用于：存储用户偏好、回忆过去的交互、从错误中学习，并跨多个轮次维护上下文。

最大内积搜索（Maximum Inner Product Search, MIPS）

"MIPS is a critical operation in many machine learning applications, including recommendation systems, information retrieval, and natural language processing. The goal of MIPS is to find the top-k items in a database that have the highest inner product with a query vector."

MIPS 是许多机器学习应用中的关键操作，包括推荐系统、信息检索和自然语言处理。MIPS 的目标是找到数据库中与查询向量具有最高内积的前 k 个项目。## 组件三：工具使用（Component Three: Tool Use）

工具使用是 LLM 驱动代理的关键组件。它允许代理与外部系统交互、检索信息并在现实世界中执行操作。

案例研究（Case Studies）

科学发现代理（Scientific Discovery Agent）

"ChemCrow (Branavan et al. 2023) is a domain-specific example of an LLM-powered autonomous agent designed to accomplish tasks in the field of chemistry. It integrates 18 expert-designed tools to autonomously execute tasks like drug discovery, materials design, and chemical reaction optimization."

ChemCrow（Branavan 等，2023）是一个 LLM 驱动的自主代理在化学领域的领域特定示例。它集成了 18 个专家设计的工具，以自主执行药物发现、材料设计和化学反应优化等任务。

生成代理模拟（Generative Agents Simulation）

"Generative Agents (Park et al. 2023) is a groundbreaking work that introduces LLM-powered agents with memory, reflection, and planning capabilities to simulate human behavior in a virtual town called Smallville. These agents wake up, engage in daily activities, form relationships, and even throw parties, all based on their memories and reflections."

生成代理（Park 等，2023）是一项开创性的工作，引入了具有记忆、反思和规划能力的 LLM 驱动代理，以模拟名为 Smallville 的虚拟小镇中的人类行为。这些代理醒来、参与日常活动、建立关系，甚至举办派对，所有这些都基于它们的记忆和反思。

概念验证示例（Proof-of-Concept Examples）

"AutoGPT (Richards, 2023) is a popular open-source project that demonstrates the potential of autonomous LLM-powered agents. It chains together LLM calls to achieve a goal set in natural language, with the ability to create and revise its own prompts, search the internet, and manage long-term and short-term memory."

AutoGPT（Richards, 2023）是一个流行的开源项目，展示了自主 LLM 驱动代理的潜力。它将 LLM 调用链接在一起以实现用自然语言设定的目标，能够创建和修改自己的提示、搜索互联网并管理长期和短期记忆。

"GPT-Engineer (Osika, 2023) is another project that focuses on generating code repositories based on natural language requirements. It clarifies requirements, generates code, and asks for human input when needed."

GPT-Engineer（Osika, 2023）是另一个专注于根据自然语言需求生成代码存储库的项目。它澄清需求、生成代码，并在需要时请求人类输入。

"BabyAGI (Nakajima, 2023) is a Python script that uses OpenAI's API to create, prioritize, and execute tasks based on a given objective. It maintains a task list, pulls tasks based on priority, sends them to the execution agent, and updates the list based on the results."

BabyAGI（Nakajima, 2023）是一个 Python 脚本，使用 OpenAI 的 API 根据给定目标创建、优先排序和执行任务。它维护任务列表，根据优先级拉取任务，将其发送给执行代理，并根据结果更新列表。
