SOP · 💰 报价签约专项（独立于接单 SOP）

报价是接单的临门一脚，单独拎出来。

报价流程（来自方法论）

01. 大忌: 按Agent数量报价

采购问一个Agent多少钱 → 敢按数量报价=卖工具, 不是做转型。

出处：制造业AI落地官

02. 正确: Benchmark量化成钱

①选5个业务流做基准(部门人员→SOP→对比AI工作流→算产出率提升) ②量化: 一年省100万/月省8.3万 ③合同按结果导向(降本增效结果挂钩)——差异化, 大厂还在卖软件。

出处：zionisreal(宁波20万单)

03. 定价锚点

500人规模传统企业 10-15万/单; 小智FDE入企 20万/单(武汉公司已打款)。

出处：zionisreal/小智

04. 先盘业务资产再谈AI，别推大而全

客户想上AI时，先别急着报价或讲方案。先帮他找到业务里『真实+重复+能留下数据+AI做完人能较快判断对错』的具体工作，比如售后问答、报表汇总。数据只是第一步，真正难的是把人的经验说清楚，所以要把这块业务的经验梳理成规则。不具备这两个条件，就劝客户先别花钱。

出处：引2条: 王总/实操、DD讲AI

05. 四阶段落地法：导入-典范-扩展-生化

别想一口吃成胖子，分四步走。第一步导入期，请专家讲落地案例，和管理层对齐认知、消除恐惧。第二步典范期，选一个最痛、最标准、重复性最高的业务做试点，快速做demo，核算投产比。第三步扩展期，把验证过的场景复制到相似部门，项目制常态化。第四步生化期，把AI融入公司战略，建知识库和AI平台，优化组织结构。没有数字化就没有全面的AI智能化，四阶段本质都是积累企业数据和知识库。

出处：引1条: 旭东AI

06. FDE三步入企诊断法：找数据、挖痛点、翻规则

别在办公室谈方案，要驻进客户生产现场。第一步先找数据在哪，Excel、OA、群文件、CRM、日报，找不到数据后面全是空话。第二步跟创始人或1号位挖痛点，不问『你想用AI干啥』，要问哪个环节最浪费时间、哪个部门天天重复劳动、哪个流程卡交付。第三步把业务问题翻译成AI能执行的规则，用Agent或知识库落地到员工天天用的场景里，比如接飞书或CRM。

出处：引1条: 旭东AI

07. 报价按省钱的账算，不按Agent个数算

别按Agent数量或人天报价，那是卖工具。先选5个业务流做Benchmark，把部门人员工作做成SOP，对比AI工作流，算出产出率提升。然后按实际业务量量化，比如帮企业一年省100万，就按这个省钱数字报价。合同可以按结果导向来签，比如降本增效结果分成或对赌。市场平均客单价10-15万，目标客户是500人规模、用传统办公软件、微信传文件、急需降本增效的中小制造或贸易企业。

出处：引2条: zionisreal、制造业AI落地官

08. 客户问价先带他看业务复杂度，再谈诊断报价

客户问『一个Agent多少钱』时，别急着回答。先带他去看业务现场的真实复杂度，比如一个售后Agent要接产品型号、技术手册版本、保修政策、历史记录、配件返修流程，远不是把SOP写成提示词。让客户明白这不是买几个Agent装进公司的事。然后按『诊断+方案+落地』三段式报价，而不是按Agent数量报。

出处：引1条: 制造业AI落地官

09. 数据底子差先卖数字化小单，分两步走

遇到连ERP和知识库都没有、还在用Excel记生产流程的企业，别推AI大项目，那必死。先卖『补数据/数字化』的小单，帮客户把数据沉淀下来，完成数字化转型的第一步。等数据有了，再谈AI项目。很多AI项目死在没数据，所以第一步必须先补数字化课。

出处：引1条: 旭东AI

10. 轻量交付五步SOP：诊断-Demo-落地-优化-培训

接单后按五步走：第一步业务诊断，深入流程挖高价值场景和真痛点，不是客户嘴上说的。第二步Demo验证，快速搭最小可用MVP，不用完美先跑通。第三步落地实施，接真实业务数据打通系统链路。第四步运行优化，观测效果调流程。第五步培训迭代，培训企业内部负责人，沉淀方法论文档，让他能长期迭代。核心是轻量起步、试点验证再规模化，避免交付即停滞。

出处：引1条: 旭东AI

11. 把技术方案翻译成『少雇一个人』

老板买的从来不是AI，是『少雇一个人』。老板只算一笔账：岗位一年十几万工资能不能省下来。谈单时别讲技术细节，直接把方案翻译成『这活以后不用人盯了』，签约速度快很多。同时要留兜底，AI做的活要加人工确认按钮，有人验收，项目烂尾概率会小很多。

出处：引1条: 清华鑫哥

12. 企业知识库项目，七成功夫在梳理脏乱文档

客户以为知识库项目是AI的事，其实AI只占3成功夫，7成是帮客户梳理十年乱文档。这7成脏活客户愿意付钱，因为这是壁垒。别嫌脏活累，脏活才有护城河。梳理完文档再上AI，项目才稳。

出处：引1条: 清华鑫哥

13. 先做刚性自动化，AI只做降门槛和辅助

别迷信AI百分百准确，核心执行环节必须用确定性规则。比如智慧农业，把农艺专家经验写成固定代码，土壤湿度低于阈值且在水位足够时自动开阀，不依赖AI推理。AI只做三件事：自然语言交互、数据整合决策、执行前预审提醒。系统要保留手动兜底，一键切换手动模式，让一线人员有掌控感。不推翻老系统，在原有设备上新增模块，用新壳包老系统平滑升级。

出处：引1条: 智慧农业落地纪实

14. 用四象限分类问题，优先做策略级P0需求

别被团队『体感痛』带偏，比如滑稿、剪辑虽痛苦，但在公司增长结构里优先级低，要忍住先不优化。花3天全链路访谈各环节关键人，用AI清洗归类问题，画出业务地图。把问题分成战略、策略、底线、优化四类，战略问题重要不紧急，优化问题体感强但对增长无用，优先做能推动增长的『策略问题』。找到P0级需求，比如内容公司最怕选错题，就做选题爆款预测系统。

出处：引1条: 程前朋友圈AI改造

15. AI改造先找能带来增长的关键策略，而非局部提效

AI改造企业流程，先别急着优化痛点。要定位能带来增长的关键策略问题，比如内容公司单条成本十几万、周期数月，最怕一开始选错题，那最高优先级就是选题与爆款前置判断系统。对电商，数字人填补凌晨0-8点空档、AI生图替代实拍降本90%以上，这些是能直接带来增收的策略点。找到这类问题再上AI，效果才明显。

出处：引2条: 程前朋友圈、森马电商

16. AI生成内容必须人工审核，防细节错误

AI生图或生成内容会有细节错误，比如领标变形、面料纹理不对、头发丝乱，必须人工审核修正，不能直接上线，否则货不对板影响转化。要设专门的AI设计师岗位，负责用AI出图并仔细检查细节。数字人直播也要能实时回复弹幕，不能只是循环播放。

出处：引1条: 森马电商

17. 做B端靠内容获客，一个视频等于24小时自动营业的销售

做B端AI落地服务，别只混圈子攒饭局，要持续发抖音、公众号内容。客户都是看内容找来的，一个视频等于24小时自动营业的销售，边际成本为0。窗口期就这一两年，老板知道AI重要但不知道找谁，小团队先跑通、先收钱、先攒案例，方向边跑边调。别把FDE当终身职业，趁窗口期快速积累案例，交付要产品化可复制，别靠个人时间换钱。

出处：引2条: 清华鑫哥、曲率出逃

见客户时的报价话术（叠权威层）

"我们的报价不是按 Agent 数量，是按帮您省的钱——这是参照 Anthropic 企业 Agent 评估白皮书 的 4 层指标体系 + AWS 6 维生产就绪矩阵。
验收标准分模型层 / 任务层 / 业务层 / 经济层，每一项都有客观数据。
风险分级参照 Google Agent Design Framework 的 4 级处理，Anthropic 的 5 级，OpenAI 的 3 级——三家头部厂商收敛到同一套，您尽管放心。"

合同里必须写清的 5 件事

  1. 交付标准：生产就绪，不是 POC（参照 A1）
  2. 风险分级动作表：L0-L4 每级哪些动作（参照 A2 + D1 + D3）
  3. 可验证指标：响应时长 / 准确率 / 节省金额（参照 A3）
  4. 业务回滚机制：Agent 出错如何撤销影响（参照 A2 + B2）
  5. 数据安全 + 审计：保留时长 / 隔离方式（参照 B4 + D2）
