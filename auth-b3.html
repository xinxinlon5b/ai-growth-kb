1. 摘要

Retrieval-Augmented Generation (RAG) 是一种用于知识密集型自然语言处理任务的生成方法。它结合了检索和生成技术，通过检索相关文档来增强生成过程，从而提高生成文本的质量和相关性。RAG 方法特别适用于需要大量背景知识的任务，如问答、摘要和对话系统。

2. 引言

在自然语言处理（NLP）任务中，生成高质量的文本是一个挑战。传统的生成方法往往依赖于模型内部的知识，这可能导致生成的文本缺乏相关性和准确性。为了解决这一问题，我们提出了一种新的生成方法——Retrieval-Augmented Generation (RAG)。RAG 结合了检索和生成技术，通过检索相关文档来增强生成过程，从而提高生成文本的质量和相关性。

3. 方法

3.1 模型架构

RAG 方法的核心是将检索和生成过程结合起来。具体来说，RAG 包含两个主要组件：检索器（Retriever）和生成器（Generator）。检索器负责从大量文档中检索与给定查询相关的文档片段，生成器则基于这些文档片段生成最终的文本。

3.1.1 检索器

检索器是一个基于编码-解码框架的模型，用于从大量文档中检索与给定查询相关的文档片段。检索器的输入是查询，输出是与查询相关的文档片段。检索器可以使用预训练的模型，也可以使用专门针对特定任务的模型。

3.1.2 生成器

生成器是一个基于编码-解码框架的模型，用于生成最终的文本。生成器的输入是检索器输出的文档片段，输出是生成的文本。生成器可以使用预训练的模型，也可以使用专门针对特定任务的模型。

3.2 数据处理

在 RAG 方法中，数据处理主要包括两个步骤：文档预处理和查询生成。文档预处理包括分词、去除停用词、词干提取等步骤，以生成适合检索器处理的文档片段。查询生成则是根据任务需求生成查询，以便检索器能够检索到相关的文档片段。

3.3 实现细节

在 RAG 方法的实现中，我们使用了以下技术细节：

  • 编码-解码框架：RAG 使用编码-解码框架来实现检索和生成过程。
  • 预训练模型：RAG 使用预训练的编码器和解码器模型来提高生成文本的质量。
  • 文档片段：RAG 生成的文本是基于检索到的文档片段生成的，这些片段可以来自多个文档。

4. 实验

4.1 实验设置

我们使用了两个数据集来评估 RAG 方法：一个用于问答任务，另一个用于摘要任务。对于问答任务，我们使用了 SQuAD 数据集；对于摘要任务，我们使用了 CNN/Daily Mail 数据集。

4.2 实验结果

实验结果表明，RAG 方法在问答和摘要任务上都取得了显著的性能提升。与传统的生成方法相比，RAG 方法生成的文本更加准确和相关。此外，RAG 方法还能够处理复杂的查询，生成高质量的文本。

4.3 结果分析

通过分析实验结果，我们发现 RAG 方法在处理复杂查询时表现出色。RAG 方法能够从大量文档中检索到相关的文档片段，并生成高质量的文本。此外，RAG 方法还能够处理多种类型的查询，包括开放式和封闭式查询。

5. 结论

Retrieval-Augmented Generation (RAG) 是一种有效的生成方法，特别适用于需要大量背景知识的任务。通过结合检索和生成技术，RAG 能够提高生成文本的质量和相关性。未来的工作可以进一步探索 RAG 在其他任务中的应用，如对话系统和机器翻译。

---## 摘要（Abstract）

"Large pre-trained language models have been shown to store factual knowledge in their parameters, and achieve state-of-the-art results when fine-tuned on downstream NLP tasks. However, their ability to access and precisely manipulate knowledge is still limited, and hence on knowledge-intensive tasks, their performance lags behind task-specific architectures. Additionally, providing provenance for their decisions and updating their world knowledge remain open research problems."

大型预训练语言模型已被证明能在其参数中存储事实知识，并在下游 NLP 任务上微调时取得最先进的结果。然而，它们访问和精确操纵知识的能力仍然有限，因此在知识密集型任务上，它们的性能落后于任务特定架构。此外，为其决策提供出处和更新其世界知识仍然是开放的研究问题。

"Pre-trained models with a differentiable access mechanism to explicit non-parametric memory have so far been only investigated for extractive downstream tasks. We explore a general-purpose fine-tuning recipe for retrieval-augmented generation (RAG) — models which combine pre-trained parametric and non-parametric memory for language generation."

迄今为止，具有可微分访问显式非参数记忆机制的预训练模型仅在抽取式下游任务中进行了研究。我们探索了一种用于检索增强生成（RAG）的通用微调配方——这类模型将预训练的参数记忆和非参数记忆结合用于语言生成。

"We introduce RAG models where the parametric memory is a pre-trained seq2seq model and the non-parametric memory is a dense vector index of Wikipedia, accessed with a pre-trained neural retriever. We compare two RAG formulations, one which conditions on the same retrieved passages across the whole generated sequence, and another which can use different passages per token."

我们引入了 RAG 模型，其中参数记忆是一个预训练的 seq2seq 模型，非参数记忆是维基百科的稠密向量索引，通过预训练的神经检索器访问。我们比较了两种 RAG 公式，一种在整个生成的序列上以相同的检索段落为条件，另一种可以对每个 token 使用不同的段落。

"We fine-tune and evaluate our models on a wide range of knowledge-intensive NLP tasks and set the state of the art on three open domain QA tasks, outperforming parametric seq2seq models and task-specific retrieve-and-extract architectures. For language generation tasks, we find that RAG models generate more specific, diverse and factual language than a state-of-the-art parametric-only seq2seq baseline."

我们在广泛的知识密集型 NLP 任务上微调和评估了我们的模型，并在三个开放域问答任务上取得了最先进的结果，超越了参数化 seq2seq 模型和任务特定的检索-抽取架构。对于语言生成任务，我们发现 RAG 模型生成的语言比最先进的仅参数化 seq2seq 基线更具体、更多样、更真实。

"Pre-trained neural language models have been shown to learn a substantial amount of in-depth knowledge from data [47]. They can do so without any access to an external memory, as a parameterized implicit knowledge base [51, 52]."

预训练的神经语言模型已被证明能从数据中学习大量深入的知识。它们可以在没有任何外部记忆访问的情况下做到这一点，作为一个参数化的隐式知识库。

虽然这一发展令人兴奋，但这类模型确实有缺点：它们不能轻易扩展或修改其记忆，不能直接提供对其预测的洞察，并且可能产生"幻觉"。

"Hybrid models that combine parametric memory with non-parametric (i.e., retrieval-based) memories can address some of these issues because knowledge can be directly revised and expanded, and accessed knowledge can be inspected and interpreted."

将参数记忆与非参数（即基于检索的）记忆相结合的混合模型可以解决其中一些问题，因为知识可以被直接修改和扩展，访问的知识可以被检查和解释。

2.1 模型架构

"RAG consists of a retriever pη(z|x) that returns a distribution over top-K document passages z given an input sequence x, and a generator pθ(yi|x, z, y1:i−1) that generates the current token given the previous i-1 tokens, the original input x, and the retrieved passage z."

RAG 由一个检索器 pη(z|x) 和一个生成器 pθ(yi|x, z, y1:i−1) 组成。检索器返回给定输入序列 x 的 top-K 文档段落 z 的分布，生成器给定前 i-1 个 token、原始输入 x 和检索到的段落 z 生成当前 token。

2.2 两种 RAG 公式

"We explore two RAG formulations: (1) RAG-Sequence, which conditions on the same retrieved passage throughout the whole generated sequence; and (2) RAG-Token, which can use different passages per token."

我们探索了两种 RAG 公式：(1) RAG-Sequence，它在整个生成的序列中都以相同的检索段落为条件；(2) RAG-Token，它可以对每个 token 使用不同的段落。

2.3 检索器（Retriever）

"The retriever is a Dense Passage Retriever (DPR), which uses a bi-encoder architecture where the query encoder and document encoder are both BERT-base models. The similarity between query and document is computed as the inner product of their encoded representations."

检索器是一个稠密段落检索器（DPR），它使用双编码器架构，其中查询编码器和文档编码器都是 BERT-base 模型。查询和文档之间的相似度计算为它们编码表示的内积。

2.4 生成器（Generator）

"The generator is a BART-large model, a pre-trained seq2seq model with an encoder-decoder architecture. The generator uses the retrieved passage as additional context to generate the output."

生成器是一个 BART-large 模型，一个具有编码器-解码器架构的预训练 seq2seq 模型。生成器使用检索到的段落作为额外上下文来生成输出。## 3. 实验（Experiments）

我们在广泛的知识密集型 NLP 任务上评估 RAG：开放域问答（Natural Questions、TriviaQA、WebQuestions、CuratedTrec）、抽象式问答（MS-MARCO）、Jeopardy 问题生成和事实核查（FEVER）。

RAG 的核心概念

"RAG (Retrieval-Augmented Generation) is a technique that enhances the capabilities of a language model by retrieving relevant documents from a knowledge base before generating a response. This allows the model to access up-to-date, domain-specific information that it may not have been trained on."

RAG（检索增强生成）是一种通过在生成响应之前从知识库中检索相关文档来增强语言模型能力的技术。这允许模型访问它可能没有训练过的最新的、特定领域的信息。

RAG 的组件

"A RAG system consists of three main components: (1) a knowledge base of documents; (2) a retrieval system that finds relevant documents; and (3) a generation model that uses the retrieved documents to generate a response."

RAG 系统由三个主要组件组成：(1) 文档知识库；(2) 查找相关文档的检索系统；(3) 使用检索到的文档生成响应的生成模型。

RAG 与微调的区别

"RAG is different from fine-tuning: fine-tuning changes the model's weights to embed knowledge, while RAG retrieves knowledge at inference time without changing the model. RAG is more flexible for frequently changing knowledge and provides provenance for answers."

RAG 不同于微调：微调改变模型的权重来嵌入知识，而 RAG 在推理时检索知识而不改变模型。RAG 对于频繁变化的知识更灵活，并为答案提供出处。## 第三部分：幻觉（Hallucination）

来源：Lilian Weng《LLMs 中的幻觉》(2024)

幻觉的定义

"Hallucination in LLMs refers to the generation of content that is nonsensical or unfaithful to the provided source content. Hallucination can be categorized into two types: (1) factuality hallucination, where the generated content conflicts with verifiable real-world facts; and (2) faithfulness hallucination, where the generated content is inconsistent with the given context or instruction."

LLM 中的幻觉是指生成无意义或不忠实于所提供源内容的内容。幻觉可以分为两类：(1) 事实性幻觉，生成的内容与可验证的现实世界事实相冲突；(2) 忠实性幻觉，生成的内容与给定的上下文或指令不一致。

幻觉的根源

"Hallucination stems from several factors: (1) training data limitations and biases; (2) the inherent probabilistic nature of LLMs; (3) knowledge cutoff; (4) imperfect alignment; and (5) the pressure to generate fluent responses."

幻觉源于几个因素：(1) 训练数据的局限性和偏差；(2) LLM 固有的概率性质；(3) 知识截止；(4) 不完美的对齐；(5) 生成流畅响应的压力。

缓解幻觉的方法

"RAG is one of the most effective methods to mitigate hallucination, by grounding the model's responses in retrieved documents. Other methods include: improving training data quality, using better alignment techniques, and implementing output validation."

RAG 是通过将模型的响应基于检索到的文档来减轻幻觉的最有效方法之一。其他方法包括：提高训练数据质量、使用更好的对齐技术和实施输出验证。## 翻译附记

RAG 原理

RAG（Retrieval-Augmented Generation）是一种结合了检索和生成的模型架构。它通过检索外部知识来增强生成过程，从而提高生成文本的质量和相关性。RAG 模型由两个主要组件组成：检索器（Retriever）和生成器（Generator）。

模型架构

RAG 模型的架构如图 1 所示。输入文本首先通过检索器进行检索，检索器从外部知识库中检索相关的信息。检索到的信息随后传递给生成器，生成器利用这些信息生成最终的输出文本。

两种 RAG 公式

RAG 模型有两种主要的公式来描述其工作原理。第一种公式是基于检索器和生成器的联合训练，第二种公式是基于检索器和生成器的独立训练。这两种公式在训练过程中分别采用了不同的策略。

检索器

检索器负责从外部知识库中检索相关的信息。检索器可以使用不同的方法，如基于索引的检索、基于相似度的检索等。检索器的性能直接影响到生成器生成的文本的质量。

生成器

生成器负责生成最终的输出文本。生成器可以使用不同的模型架构，如基于序列到序列（Seq2Seq）的模型、基于Transformer的模型等。生成器的性能直接影响到生成文本的质量和相关性。

实验

实验部分展示了 RAG 模型在多个数据集上的表现。实验结果表明，RAG 模型在生成高质量文本方面具有显著的优势。生成的质量主要体现在文本的相关性、流畅性和准确性上。

结论

RAG 模型通过结合检索和生成，显著提高了生成文本的质量和相关性。未来的研究可以进一步探索 RAG 模型在不同应用场景中的表现，以及如何优化检索器和生成器的性能。

Lilian Weng 幻觉研究

Lilian Weng 的幻觉研究详细介绍了幻觉的定义、根源以及缓解方法。

定义

幻觉是指模型生成的文本与真实世界不符的情况。幻觉可以表现为生成的文本与真实世界不符，或者生成的文本与模型训练数据不符。

根源

幻觉的根源主要包括模型的训练数据、模型的架构以及模型的训练过程。模型的训练数据可能包含错误或偏差，模型的架构可能无法准确捕捉真实世界的复杂性，模型的训练过程可能无法充分训练模型以避免生成幻觉。

缓解方法

缓解幻觉的方法主要包括改进训练数据、改进模型架构以及改进训练过程。改进训练数据可以减少模型训练数据中的错误或偏差，改进模型架构可以提高模型对真实世界的捕捉能力，改进训练过程可以提高模型的泛化能力，从而减少生成幻觉的可能性。
