04 · 工具链（47 个要点 · 实战版）

自用工具栈，按场景分。每条标"用 / 不用"判断 + 工具组合 + 入门指南。

一、模型层（5 条）

1. Claude (Anthropic)

  • 强项：长上下文（200K）、代码能力强、推理准确
  • 弱项：国内访问慢、价格中高
  • 何时用：复杂推理 / 代码 / 长文档分析
  • 何时不用：实时性要求高 / 简单任务
  • 价格：Sonnet $3/M input，$15/M output
  • 替代品：国产替代用 Kimi K2（中文强）

2. GPT-4 (OpenAI)

  • 强项：通用能力平衡、Function Calling 成熟、工具生态丰富
  • 弱项：价格高、长上下文不如 Claude
  • 何时用：需要 Function Calling / 工具调用标准场景
  • 何时不用：长文档 / 纯推理任务
  • 替代品：GPT-4o mini（便宜）

3. Kimi K2 (Moonshot)

  • 强项：中文处理优秀、上下文长、价格便宜
  • 弱项：英文任务稍弱
  • 何时用：中文长文档 / 中文 Agent / 国内业务
  • 何时不用：英文 / 复杂代码

4. DeepSeek V3

  • 强项：性价比最高、推理能力强、开源
  • 弱项：访问偶尔波动
  • 何时用：大批量处理 / 成本敏感场景
  • 何时不用：对响应延迟要求极严

5. Qwen3 (通义千问)

  • 强项：开源可本地跑、阿里生态
  • 弱项：通用任务稍弱
  • 何时用：私有部署 / 数据敏感 / 中文

二、Agent 平台层（6 条）

6. OpenClaw

  • 强项：多 Agent 协作 / Skill 管理 / Hermes 框架
  • 弱项：学习曲线陡
  • 何时用：复杂业务流程 / 多角色协作
  • 替代品：Coze（更轻量）

7. Coze（扣子）

  • 强项：无代码搭 Agent / 国内生态好 / 上手快
  • 弱项：深度定制能力有限
  • 何时用：快速验证 / 中小企业 / 非技术团队
  • 何时不用：需要深度集成业务系统

8. Dify

  • 强项：工作流编排 / RAG 友好 / 私有化可
  • 弱项：学习成本中等
  • 何时用：RAG + Agent 一体化需求
  • 何时不用：纯对话型 Agent

9. LangChain

  • 强项：灵活 / 生态全 / Python 友好
  • 弱项：抽象层多、新人难
  • 何时用：复杂自定义 Agent
  • 何时不用：MVP 阶段

10. LlamaIndex

  • 强项：RAG 专注 / 数据连接器丰富
  • 弱项：不是全功能 Agent 平台
  • 何时用：RAG 为主的项目
  • 何时不用：复杂 Agent 流程

11. n8n

  • 强项：可视化工作流 / 集成多系统
  • 弱项：AI 能力需外挂
  • 何时用：系统集成 + 简单 AI
  • 何时不用：复杂推理

三、编程工具层（5 条）

12. Cursor

  • 强项：AI 编程 / 多文件编辑 / 上下文理解
  • 弱项：订阅费
  • 何时用：日常开发 / 改代码 / 学代码
  • 入门：5 分钟上手

13. Claude Code

  • 强项：命令行 AI 编程 / 长任务
  • 弱项：要会用终端
  • 何时用：自动化代码任务 / 重构

14. v0 (Vercel)

  • 强项：UI 组件生成 / Tailwind + React
  • 弱项：只做前端
  • 何时用：快速搭前端 Demo
  • 何时不用：复杂后端逻辑

15. Bolt (StackBlitz)

  • 强项：全栈 Web App 生成
  • 弱项：复杂定制有限
  • 何时用：快速验证产品想法

16. Codex (OpenAI)

  • 强项：长任务自动化
  • 弱项：需要精细引导
  • 何时用：跨多文件的代码任务

四、数据 / 存储层（5 条）

17. PostgreSQL

  • 强项：稳定 / 通用 / SQL 强大
  • 何时用：业务系统主库

  • 何时用：MVP 阶段 RAG
  • 替代品：Milvus（私有化）

19. Milvus

  • 何时用：大规模 RAG / 私有化

20. Weaviate

  • 强项：模块化 / 多模态支持
  • 何时用：需要混合检索

21. FAISS

  • 强项：本地 / 极快
  • 弱项：功能少
  • 何时用：研究 / 小规模

十一、工具组合推荐（4 套）

组合 A：起步装备（月成本 < 100 元）

  • 模型：Kimi K2 + DeepSeek V3 + GPT-4o mini
  • Agent：Coze（免费版）
  • 编程：Cursor（学生版免费）
  • 笔记：Obsidian（免费）
  • 部署：Cloudflare Pages（免费）
  • 总成本：约 50-100 元/月

组合 B：FDE 实战装备（月成本 500-2000 元）

  • 模型：Claude Sonnet 4 + GPT-4 + Kimi K2
  • Agent：OpenClaw / Dify（自托管）
  • 编程：Cursor + Claude Code
  • 知识库：Obsidian + Notion
  • 可观测：Langfuse（自托管）
  • 部署：Vercel + GitHub Actions
  • 总成本：约 500-2000 元/月

组合 C：企业交付装备（月成本 1-5 万）

  • 模型：Claude + GPT-4 + 国产备用
  • Agent：Dify 企业版 / 自研
  • 数据库：PostgreSQL + Pinecone
  • 安全：Microsoft Presidio + HashiCorp Vault
  • 监控：Langfuse / Datadog
  • 部署：Docker + K8s（私有）
  • 总成本：约 1-5 万/月

组合 D：自建 AI 中台装备（一次性 10-50 万）

  • 模型：Claude + GPT-4 + Ollama（本地）
  • 平台：Dify 企业版 / 自研
  • 存储：PostgreSQL + Milvus
  • 安全：全套
  • 监控：Prometheus + Grafana
  • 部署：自建 K8s 集群
  • 总成本：10-50 万（一次性）+ 月运营 2-5 万

十二、3 个反模式

反模式 1：工具囤积

症状：收藏 47 个工具都用不上。
风险：维护成本高 / 切换疲劳。
正解：从组合 A 起步，按需升级。

反模式 2：只看贵的

症状：直接上 GPT-4 + Claude + 全套企业版。
风险：烧钱 / ROI 不清晰。
正解：先免费 + 国产 + 按价值付费。

反模式 3：忽略学习曲线

症状：选最强大的工具但团队不会用。
风险：工具闲置。
正解：选团队能上手的，能力到了再升级。
