SOP · 📹 内容 IP 方向（长期复利）

方向标签：把 AI 实战做成信任资产
v2 更新：2026-09-10 — 从 5 步骨架扩到完整可执行流程

一、为什么这条路径

你有「王昕AI实战笔记」方向已被方法论反复验证——B 端客户都是看内容找来的，一个视频 = 24 小时营业的销售（清华鑫哥原话）。内容是接单方向的最佳杠杆，但不必日更；把接单 / FDE / 交付过程如实记录，就是最稀缺的"真实案例型"内容。

核心定位：不聊模型参数，聊「模型能替咱干什么」；用你自己接单 / 交付 / 踩坑的真事，别人抄不走。

二、适合谁

适合已经在做 / 想做自媒体的人；目标 = 每周 2-3 条实战记录，不追热点不追涨粉。

不要做这条路径的场景：
- 你没真实业务案例（先做接单 / 交付积累案例）
- 你想做"AI 教程搬运"（会被识别为低质内容，工具搬运工没壁垒）
- 你想 3 个月内涨到 10 万粉（不是这条路径的目标）

三、执行 SOP（5 步 · 完整版）

步骤 1：定位 = 真实实战记录（决定号的价值）

不要做：开"AI 教程"号、"AI 资讯"号、"AI 工具盘点"号——这些是工具搬运工，壁垒低、变现难。
要做：定位"FDE 实战派"——记录你接单 / 交付 / 踩坑的每一个真实过程。

三档定位（选 1 档，不要漂移）：
| 定位 | 内容形态 | 受众 |
|---|---|---|
| FDE 实战派 | 客户案例 + 交付过程 + 报价思考 | 想找 FDE 服务的企业 / 想转 FDE 的人 |
| AI 行业观察 | 行业访谈 + 趋势研判 + 深度长文 | AI 行业从业者 / 投资人 |
| AI 自用效率 | 自己用 AI 提效的流程 + 工具评测 | 知识工作者 / 提效控 |

你的现状 = 定位 1（FDE 实战派）——和你的接单 / 交付路径完美咬合。

风格库（学一席 / 李继庚 / 三联生活周刊的克制写法）：
- 写"我做了什么 + 怎么做的 + 学到什么"
- 不用"震惊体""标题党"
- 案例细节具体到"客户叫什么 + 痛点是什么 + 报价多少"
- 少形容词、多动词、多数字

步骤 2：轻量高频起号（决定能不能跑起来）

不要做：追求精致（请人拍 + 后期剪辑 + 配音配乐）。
要做：口播 + 手机剪（"徐兆猛轻量高频"法）。

真实案例：王昕 IP 起号就是"手机 + 口播 + 即兴"——3 个月从 0 到 5000 精准粉，全是接单潜在客户。

轻量装备：
- 拍摄：iPhone + 一支领夹麦
- 灯光：自然光 + 一盏台灯
- 剪辑：剪映（自动字幕 + 简单裁剪）
- 选题：记在备忘录里，随时记

发布节奏（用户能持续跑的）：
- 每周 2-3 条实战记录（不追日更）
- 每条 30-60 秒（抖音黄金时长）
- 不追热点（热点和你定位无关的不发）

前 30 天的内容公式（用现成案例库改）：
- 第 1 周：「我是谁 + 我做什么 + 为什么」
- 第 2-3 周：3 个真实客户场景（可脱敏）
- 第 4 周：第一个工具 / 流程分享

步骤 3：爆款拆成公式（决定能不能稳定输出）

不要做：每天想破头选题。
要做：看到好视频就拆结构，存进弹药库，用选题库多维打分决定做什么。

爆款结构公式（光羽 + 柱子哥总结）：

钩子（0-3 秒）：痛点场景 / 反常识结论 / 数字震撼
冲突（3-10 秒）：错误做法 / 常见误区 / 客户坑
展示（10-40 秒）：正确做法 / 真实案例 / 工具流程
结论（40-60 秒）：行动建议 / 一句话总结

选题打分维度（柱子哥选题自动化）：
- 痛点强度（1-5）：越痛分越高
- 案例独特性（1-5）：越独门分越高
- 变现关联度（1-5）：越直接关联接单分越高
- 重复可拍性（1-5）：越能拍出多条分越高

总 ≥ 15 分才拍——低分直接 pass。

弹药库工具：
- 抖音收藏夹（看到好视频立即收藏）
- 选题表（Notion / Excel / 飞书多维表都行）
- 每周日选下周的 3 个选题

步骤 4：让 AI 替你熬夜（决定产能）

不要做：所有事都自己干。
要做：素材初筛 / 标题打分 / 发布时间这类重复活交给 AI 夜间跑，早上给你干净起点。

AI 自动化清单（SOP-04「Agent 工具链」会详细讲）：
| 任务 | 工具 | 何时跑 |
|---|---|---|
| 素材初筛 | 抖音 API + LLM 分类 | 每天凌晨 |
| 标题打分 | GPT-4 评分 | 每天早上 |
| 发布时间优化 | 数据分析 + 智能调度 | 每周一 |
| 评论区回复 | GPT-4 拟稿 + 人工审核 | 每条视频发后 1 小时 |
| 视频文案改写 | 录完口播后 | 每次拍摄后 |

柱子哥原话金句：「让 AI 替你熬夜，把省下的时间用在真判断上」—— 选题判断、内容质量、客户互动，这三件事 AI 做不了，你做。

步骤 5：导流到私域（决定能不能变现）

不要做：把流量留在公域（涨粉 ≠ 收入）。
要做：每条视频结尾留钩子，把流量沉淀成可跟进的联系人。

钩子设计（3 类都用）：
- 资料钩子：「评论区扣『手册』领《FDE 接单报价模板》」
- 清单钩子：「我整理了 10 个客户接触路径，关注后私信『路径』」
- 诊断钩子：「想知道你的业务能不能上 AI？私信我，30 分钟免费诊断」

私域承接（微信个人号 / 企业微信）：
- 加微后立刻发欢迎语 + 资料
- 标签管理（按行业 / 规模 / 阶段）
- 朋友圈每周 3 条真实工作日常
- 月度群发一次"最近在做的事"（不要硬推）

飞轮：

公域内容 → 私域沉淀 → 接单 / 案例 → 写新内容 → 公域传播

四、避坑（重要）

❌ 做"工具搬运工"——只教工具不解决业务 = 没有壁垒（学AI工具不赚钱原文）
❌ 被涨粉焦虑带偏——粉丝质量 > 数量（5000 精准粉 > 5 万泛粉）
❌ 追热点——和你定位无关的热点别发
❌ 追求精致——前 30 条别花时间在剪辑上，内容 > 形式
❌ 不沉淀私域——公域粉丝留不下 = 0 价值
❌ 群发广告——会掉粉 + 伤信任
❌ 断更——一周不发就掉粉 30%，断更 = 死号

工具 用途 何时用
