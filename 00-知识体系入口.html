四、权威支撑层怎么用

08-权威支撑/ 下有 18 张一手权威卡（A1-A3 / B1-B4 / C1-C3 / D1-D3 / E1-E6），每张含：

- 关键术语
- 与本知识库的映射
- 客户引用话术
- 原文链接

何时用：
- 见客户被问"这套方法论来源" → 亮 A 类（Anthropic / Google / AWS / OpenAI 三原厂）
- 写方案需要权威背书 → 引用 E 类（国际标准 / 行业数据）
- 学新概念想找最权威解释 → 按字母去查

三大厂商方法论横向对比（你可信度最高的弹药）：
- Anthropic：学院派工程化（Harness / 护栏）
- Google：平台化（白名单工具 / 风险分级）
- OpenAI：实用主义（Function Calling / 循环控制）

三家头部收敛到同一套方法论——这不是偏好，是行业共识。

六、常见问题

Q1: 我该从哪个 SOP 开始？

A: 看你的当前状态——
- 没客户 → SOP-02 内容 IP 起号
- 有客户没成交 → SOP-01 接单成交
- 成交了不会做 → SOP-03 FDE 入企交付
- 都在跑想加速 → SOP-04 Agent 工具链
- 有自家业务 → SOP-05 行业深耕
- 都稳了想升级 → SOP-06 认知升级

Q2: 6 条路必须全做吗？

A: 不是。建议主线 + 辅线——
- 主线：1 条路径（投入 60% 时间）
- 辅线：1-2 条路径（投入 30%）
- 长期：2-3 条路径（投入 10%）

示例组合：
- 接单成交（主）+ 内容 IP（辅）+ 认知升级（长期）
- 行业深耕（主）+ FDE 交付（辅）+ Agent 工具链（长期）

Q3: 知识库和原网站 v2.11 有什么区别？

A: 4 个核心差异：
1. 结构化：原网站是 9 个分类卡片，这版是 6 层级金字塔
2. 权威化：原网站是经验性总结，这版加 18 张一手权威卡
3. 可执行：原网站 SOP 是 5 步骨架，这版是 5-8 步完整流程 + 真实案例 + 工具清单
4. 易搜索：原网站是 SPA，这版是静态页 + 全文搜索 + 主题过滤

Q4: 怎么证明这套方法论是权威的？

A: 看 08-权威支撑/ 18 张卡——
- A 类（一手权威）：Anthropic 官方 / Google Agent Framework / OpenAI Best Practices
- B 类（工程师必读书）：Pete Hunt / Adele Lin / RAG in Action / Security
- C 类（通用方法论）：Risk-Driven Architecture / Chaos Engineering / DDD
- D 类（行业框架）：Google / AWS / OpenAI
- E 类（国际标准）：SWEBOK / ISO 12207 / NIST RMF / EU AI Act / TOGAF / PMBOK / ISO 42001

Q5: 怎么快速见客户？

A: 用 03-SOP/SOP-07-报价签约.md 的报价单模板（6 部分 + 付款节奏），加上 5 句金话术（05-话术弹药.md），加上 13 个避坑（06-避坑清单.md），加上 1 张 MIT 95% 失败率（auth-e4）—— 半小时准备，足够见客户。
