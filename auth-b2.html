---## 概述

"Building agents with LLM (large language model) as its core controller is a cool concept. Several proof-of-concepts demos, such as AutoGPT, GPT-Engineer and BabyAGI, serve as inspiring examples."

以 LLM（大型语言模型）作为核心控制器构建代理是一个酷炫的概念。几个概念验证演示，如 AutoGPT、GPT-Engineer 和 BabyAGI，作为鼓舞人心的例子。## Agent 系统概述

3 大核心组件

"在 LLM 驱动的自主代理系统中，LLM 作为代理的大脑，由几个关键组件补充：规划、记忆、工具使用**。"

在 LLM 驱动的自主代理系统中，LLM 作为代理的大脑，由几个关键组件补充：规划、记忆、工具使用。

规划（Planning）

"子目标与分解：代理将大型任务分解为更小的、可管理的子目标，从而高效处理复杂任务。反思与改进：代理可以对过去的行动进行自我批评和自我反思，从错误中学习并为未来的步骤改进它们。"

子目标与分解：代理将大型任务分解为更小的、可管理的子目标，从而高效处理复杂任务。反思与改进：代理可以对过去的行动进行自我批评和自我反思，从错误中学习并为未来的步骤改进它们。

记忆（Memory）

"短期记忆：我会考虑所有上下文内学习作为利用模型的短期记忆来学习。长期记忆：这为代理提供了在延长期间保留和回忆（无限）信息的能力，通常通过利用外部向量存储和快速检索。"

短期记忆：我会考虑所有上下文内学习作为利用模型的短期记忆来学习。长期记忆：这为代理提供了在延长期间保留和回忆（无限）信息的能力，通常通过利用外部向量存储和快速检索。

工具使用（Tool use）

"代理学习调用外部 API 以获取模型权重中缺失的额外信息，包括当前信息、代码执行能力、访问专有信息源等。"

代理学习调用外部 API 以获取模型权重中缺失的额外信息，包括当前信息、代码执行能力、访问专有信息源等。## 组件一：规划（Component One: Planning）

任务分解（Task Decomposition）

思维链（Chain-of-Thought）

"思维链（CoT；Wei 等，2022）已成为增强模型在复杂任务上性能的标准提示技术。模型被指示'逐步思考'以利用更多的测试时计算来将困难任务分解为更小更简单的步骤。"

思维链（CoT；Wei 等，2022）已成为增强模型在复杂任务上性能的标准提示技术。模型被指示'逐步思考'以利用更多的测试时计算来将困难任务分解为更小更简单的步骤。

思维树（Tree of Thoughts）

"思维树（Yao 等，2023）通过在每个步骤探索多个推理可能性来扩展 CoT。它首先将问题分解为多个思维步骤，并在每个步骤生成多个想法，创建树结构。搜索过程可以是 BFS（广度优先搜索）或 DFS（深度优先搜索）。"

思维树（Yao 等，2023）通过在每个步骤探索多个推理可能性来扩展 CoT。它首先将问题分解为多个思维步骤，并在每个步骤生成多个想法，创建树结构。搜索过程可以是 BFS（广度优先搜索）或 DFS（深度优先搜索）。

LLM+P

"LLM+P（Liu 等，2023）涉及使用预训练的 LLM 作为规划器，为现实世界中的任务生成计划，而不需要任何针对规划数据的特定 LLM 训练。"

LLM+P（Liu 等，2023）涉及使用预训练的 LLM 作为规划器，为现实世界中的任务生成计划，而不需要任何针对规划数据的特定 LLM 训练。

自我反思（Self-Reflection）

ReAct

"ReAct（Yao 等，2023）结合了推理和行动：思考 → 行动 → 观察。代理思考要做什么，采取行动，观察结果，然后思考下一步要做什么。"

ReAct（Yao 等，2023）结合了推理和行动：思考 → 行动 → 观察。代理思考要做什么，采取行动，观察结果，然后思考下一步要做什么。

Reflexion

"Reflexion（Shinn 等，2023）是一个为代理配备动态记忆和自我反思能力的框架。代理反思任务反馈，在情节记忆缓冲区中维护反思文本，并使用它在后续试验中驱动更好的决策。"

Reflexion（Shinn 等，2023）是一个为代理配备动态记忆和自我反思能力的框架。代理反思任务反馈，在情节记忆缓冲区中维护反思文本，并使用它在后续试验中驱动更好的决策。## 组件二：记忆（Component Two: Memory）

记忆类型

"Sensory memory: This is the earliest stage of memory, providing the ability to retain impressions of sensory information (visual, auditory, etc.) after the original stimuli have ended. Sensory memory typically only lasts for a few seconds. Short-term memory (STM) or working memory: It stores information that we are currently aware of and needed to carry out complex cognitive tasks such as learning and reasoning. STM has a limited capacity (about 7 items) and short duration (15-30 seconds without rehearsal). Long-term memory (LTM): LTM can store information for a remarkably long time, ranging from a few days to decades, with a virtually unlimited capacity."

感觉记忆：这是记忆的最早阶段，提供在原始刺激结束后保留感觉信息（视觉、听觉等）印象的能力。感觉记忆通常只持续几秒钟。短期记忆（STM）或工作记忆：它存储我们当前意识到的信息，并需要执行复杂的认知任务。STM 容量有限（约 7 个项目）且持续时间短。长期记忆（LTM）：LTM 可以存储信息非常长的时间，从几天到几十年，容量几乎无限。

最大内积搜索（MIPS）

"MIPS is a critical operation in many machine learning applications, including recommendation systems, information retrieval, and natural language processing. The goal of MIPS is to find the top-k items in a database that have the highest inner product with a query vector."

MIPS 是许多机器学习应用中的关键操作，包括推荐系统、信息检索和自然语言处理。MIPS 的目标是找到数据库中与查询向量具有最高内积的前 k 个项目。## 组件三：工具使用（Component Three: Tool Use）

案例研究

ChemCrow

"ChemCrow (Branavan et al. 2023) is a domain-specific example of an LLM-powered autonomous agent designed to accomplish tasks in the field of chemistry. It integrates 18 expert-designed tools to autonomously execute tasks like drug discovery, materials design, and chemical reaction optimization."

ChemCrow（Branavan 等，2023）是一个 LLM 驱动的自主代理在化学领域的领域特定示例。它集成了 18 个专家设计的工具，以自主执行药物发现、材料设计和化学反应优化等任务。

生成代理模拟

"Generative Agents (Park et al. 2023) is a groundbreaking work that introduces LLM-powered agents with memory, reflection, and planning capabilities to simulate human behavior in a virtual town called Smallville. These agents wake up, engage in daily activities, form relationships, and even throw parties, all based on their memories and reflections."

生成代理（Park 等，2023）是一项开创性的工作，引入了具有记忆、反思和规划能力的 LLM 驱动代理，以模拟名为 Smallville 的虚拟小镇中的人类行为。这些代理醒来、参与日常活动、建立关系，甚至举办派对，所有这些都基于它们的记忆和反思。

AutoGPT / GPT-Engineer / BabyAGI

"AutoGPT (Richards, 2023) is a popular open-source project that demonstrates the potential of autonomous LLM-powered agents. It chains together LLM calls to achieve a goal set in natural language, with the ability to create and revise its own prompts, search the internet, and manage long-term and short-term memory. GPT-Engineer (Osika, 2023) is another project that focuses on generating code repositories based on natural language requirements. It clarifies requirements, generates code, and asks for human input when needed. BabyAGI (Nakajima, 2023) is a Python script that uses OpenAI's API to create, prioritize, and execute tasks based on a given objective. It maintains a task list, pulls tasks based on priority, sends them to the execution agent, and updates the list based on the results."

AutoGPT（Richards，2023）是一个流行的开源项目，展示了自主 LLM 驱动代理的潜力。它将 LLM 调用链接在一起以实现用自然语言设定的目标，能够创建和修改自己的提示、搜索互联网并管理长期和短期记忆。GPT-Engineer（Osika，2023）是另一个专注于根据自然语言需求生成代码存储库的项目。它澄清需求、生成代码，并在需要时请求人类输入。BabyAGI（Nakajima，2023）是一个 Python 脚本，使用 OpenAI 的 API 根据给定目标创建、优先排序和执行任务。它维护任务列表，根据优先级拉取任务，将其发送给执行代理，并根据结果更新列表。## 挑战（Challenges）
